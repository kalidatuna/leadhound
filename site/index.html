Questions

Straight answers

Does it send messages on its own?

Never. You press send on every message. The daily limits exist to protect your accounts, not to set a target.

What data leaves my computer?

Searches go to the public sources (Freelancer.com, Reddit and so on) the way a browser would. If you sign up for the trial, your email and a device code go to the license server. If you use the hosted AI, the lead's text goes to the server and then to Anthropic to write the message. Nothing else.

Windows says "protected your PC". Is it safe?

The downloaded apps are not code-signed yet, so Windows and macOS warn you. On Windows click More info, then Run anyway. On macOS right-click the file and choose Open. The code is public if you want to check it, or install it with pip.

Is it really open source if Pro costs money?

Yes. The code is public under the MIT license. Pro is a license key for convenience features and the hosted AI. Anyone technical can read and change the code; paying supports the person who maintains it.

Will it get me banned on Reddit or other sites?

leadhound identifies itself, limits how fast it asks, and only reads public posts. When you connect an account to send, it caps messages per day and pauses between them. Cold messages can still break a site's rules, so keep them personal and short.
